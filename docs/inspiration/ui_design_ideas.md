# 客户端 UI 风格与交互演进构想

本文档记录关于 `PresenceKit-desktop` (Emerald-client) 前端界面的视觉优化、布局构想与可玩性体验提升方案。

---

## 一、 核心视觉风格方案设计

针对陪伴系统的独特情感属性，推荐以下两种极具氛围感的自定义主题（Theme Mod）：

### 1. 「霓虹极光」 (Neon Aurora) —— 赛博雾玻璃与情感霓虹
*   **设计理念**：采用暗色调，以深邃的幽蓝色作为底色，搭配霓虹粉（代表波动的情感）与荧光青（代表赛博与科技感），呈现一种赛博朋克深空与极光折射的氛围。适合梦境（Dream）模式或情感偏执（Yandere）状态下的沉浸对话。
*   **色彩体系**：
    *   底色 (`--paper`)：深邃靛灰 `oklch(0.18 0.03 260)`
    *   文字 (`--ink`)：明亮雪青 `oklch(0.96 0.01 220)`
    *   主色 (`--forest`)：赛博荧光青 `oklch(0.55 0.16 230)`
    *   强调 (`--accent`)：霓虹极光粉 `oklch(0.68 0.23 330)`
*   **CSS 特效**：
    *   气泡带有微弱的荧光阴影（Glow Shadow）。
    *   Ribbon 导航栏和 Sidebar 采用大毛玻璃模糊，并配合边缘的高光描边（Glow stroke）。

### 2. 「雨后青瓷」 (Celadon Tea) —— 禅意纸墨与传统温润
*   **设计理念**：采用亮色调，灵感源自雨后青瓷的温润和水墨宣纸的质感。以极柔和的米黄/蛋壳色为底，搭配淡雅的青瓷绿与温润的琥珀黄。适合现实陪伴、闲时浇花和撰写日记时的安宁心境。
*   **色彩体系**：
    *   底色 (`--paper`)：温润蛋壳黄 `oklch(0.97 0.01 90)`
    *   文字 (`--ink`)：徽墨焦炭灰 `oklch(0.25 0.015 80)`
    *   主色 (`--forest`)：龙泉青瓷绿 `oklch(0.50 0.07 150)`
    *   强调 (`--accent`)：琥珀蜜蜡黄 `oklch(0.72 0.08 65)`
*   **CSS 特效**：
    *   背景利用轻微的双重径向渐变，模拟手造纸张的颗粒感与光晕。
    *   边框采用超细的柔和墨线，卡片使用较大的圆角，呈现有机、无压迫感的东方古典美学。

## 二、 布局与功能交互（Layout Mods）优化

### 1. 「赛博工作台」 (Cyber-Workbench Layout)
*   **排布结构**：配合「霓虹极光」主题。
*   **slots 顺序**：`[Ribbon | Main Chat (Workbench 模板) | Sidebar]`。
*   **交互特色**：
    *   主区采用 `workbench` 模板，输入框置于右侧，与左侧滚动的消息流并排，适合大屏宽屏下多步工具执行（Path C Tool Loop）时的实时监控。
    *   左侧 Sidebar 常驻展示“潜意识 Hidden State 监测面板”与“Dream HUD 身体状态”，使赛博伴侣的底层机能一目了然。

### 2. 「禅意书房」 (Focus-Reading Layout)
*   **排布结构**：配合「雨后青瓷」主题。
*   **slots 顺序**：`[Sidebar (默认隐藏) | Main Chat (Stack 传统纵向) | Ribbon]`。
*   **交互特色**：
    *   默认隐藏 Sidebar，让聊天面板处于居中焦点位置，减少视觉噪音。
    *   大字号与 Serif 衬线体搭配，使阅读日记和消息交互像在翻阅一本装帧精美的实体手账。

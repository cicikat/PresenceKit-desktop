## Fix 1（主任务）：把"对话设置"接进偏好面板

**目标**：在偏好面板 `PreferencesPanel`（`src/windows/chat/ChatWindow.tsx:61`）新增一组"对话"设置，读写后端三个开关，取代被后端面板删掉的入口。

后端接口（同 `:8080`，settings_misc router，已存在）：
- `GET /chat-mode` / `PUT /chat-mode`（`mode`: 字段名以后端实际返回为准，**先调一次看结构再写解析**）
- `GET /chat-style` / `PUT /chat-style`
- `GET /chat-multi-message` / `PUT /chat-multi-message`（布尔：回复是否拆成多条气泡）

**实现要点（遵守 AGENTS 规则 7：HTTP 必须走 Tauri command，禁止组件里裸 `fetch`）**：

1. **Rust 侧**（`src-tauri/src/lib.rs`）：仿照现有 `load_mood_state`(:451) / `load_garden_state`(:335) 的 `authorized_request` + `require_success` 模式，新增：
   - `get_chat_settings()` → 一次性 GET 三个接口并合并返回（减少往返），或分三个 command，按你偏好。
   - `set_chat_settings(payload)` → 对应 PUT。
   - 在 `invoke_handler!` 的 `generate_handler` 列表里注册新 command。
2. **权限**：若新 command 触发能力校验，在 `src-tauri/capabilities/default.json`（或 chat 窗口对应 capability）补放行。
3. **TS 封装**：在 `src/shared/api/` 新建 `chat-settings.ts`（**不要把协议散进组件**，AGENTS 规则 3），导出 `getChatSettings()` / `setChatSettings()`。类型放 `src/shared/api/types.ts`。
4. **UI**：在 `PreferencesPanel` 现有的 `tab` 状态里——当前是 `'appearance' | 'world' | 'other'`（:62）。把这组放进 **`other`（其他）** tab，用现成的 `PrefRow` + `PrefSwitch`/下拉，与"对话信息栏"(:179 附近)同款写法：
   - 对话模式（下拉/分段）
   - 对话风格（下拉/分段）
   - 多消息分条（`PrefSwitch`）
   面板打开时 `getChatSettings()` 拉当前值，改动即 `setChatSettings()` 落库 + `toast` 反馈（失败也要提示，别静默）。

**验收**：

- 后端管理面板对应入口删除后，本客户端是这三项的**唯一控制面**，行为与原面板一致。

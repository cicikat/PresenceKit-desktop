## 1. 用户目标与完成定义

让同一个角色在 Room 与桌宠中使用一致的材质和表演能力：模型加载后自然站立；可导入动作和表情配置；通过一次角色映射复用动作；在基础动作上叠加眼神、表情和骨骼微调。用户与 agent 应能按同一份建模操作指南完成绑定、校准、导出和验收，不需要为每个角色重新搭建整套节点或修改客户端代码。

完成必须同时具备：

- [ ] 参数化 Toon 模板与逐材质绑定，在规定的参考灯光下可重复验收。
- [ ] 普通 GLB 保持可用；新增角色包可携带明确版本的配置与资源。
- [ ] 完整人体映射与参考姿势校准，支持自然站姿和待机。
- [ ] 外部动作导入、重定向、局部叠加与角色级修正。
- [ ] 表情语义映射、独立眨眼/口型、可校准的眼球骨骼或形态键注视。
- [ ] Room 与 Pet 复用相同表演核心，保持各自相机、灯光、交互和窗口生命周期。
- [ ] 用户与 agent 可照做的建模绑定指南、最小示例和逐项验收记录。

不承诺任意 Blender 节点或 Cycles 光追画面原样移植。Toon 是着色风格；光追是渲染技术。首期基于现有 Three.js 渲染路径，不迁移 Unity/Godot，不增加光追引擎，不扩展手机 3D，不处理场景/道具资产协议，不修改后端聊天、语音或摄像头感知链。

## 4. 拟议数据和运行合同

### 4.1 资产包

拟议 `.ptchar` 是数据包，不携带可执行脚本或任意 Shader 源码。模板实现由客户端提供。资源可内嵌 GLB；已经内嵌的贴图无需重复放入 textures。

```text
character.ptchar
  manifest.json
  model.glb
  materials/materials.json
  rig/humanoid.json
  rig/calibration.json
  expressions/expressions.json
  motions/                     # 可选：已支持格式的动作及描述
  textures/                    # 可选：模型外部的模板贴图
  preview.png                  # 可选
```

此树为草案，CA-01 冻结最小 schema 后才成为规范。必须定义 schemaVersion、assetId、revision、最小运行时能力、模型引用、材质/骨骼/表情/动作引用、来源与许可。assetId 与后端角色 ID 分离；移动或改名不应串用他人的校准，模型内容变更必须使过期节点绑定失效并要求复核。

逐材质与逐节点使用包内明确引用，名称只作提示和自动识别候选；重复名称必须消歧。重导出导致索引变化时须重生成/校验，不能把旧索引当永久 ID。形态键绑定同时指定目标网格与目标键，避免所有同名键被无意驱动。

有效配置优先级拟定为：客户端默认 < 包默认 < 本机该资产修正 < 本轮临时表演。临时表演不落盘；恢复默认只清本机覆盖，不改包。区分资产 revision、schemaVersion 与本地设置版本。模型替换、窗口同步及回滚策略在 CA-01 明确。

### 4.2 骨骼与表演

保留源模型骨架及蒙皮，不在运行时重新绑定网格。语义映射参考 VRM humanoid：hips、spine、chest、neck、head、左右肩/上臂/前臂/手、左右大腿/小腿/脚；手指、脚趾、眼睛等按能力扩展。半身角色允许缺腿；哪些动作因此不可用必须显式报告。

严格区分 bind pose、retarget reference pose、自然展示 pose；校准不能无意修改 inverse bind matrices。坐标合同注明导出空间 Y-up/+Z 前向与 Blender 原生编辑坐标的转换、角度单位、左右定义、局部/世界空间、长度单位及 quaternion 乘法顺序。不可用统一 Euler 偏角猜所有角色的手臂方向。

帧内语义顺序：基础站姿/clip → 动作层混合与角色修正 → 允许的程序化表演 → 接触/IK 修正 → 依赖最终身体姿态的弹簧链；表情权重单独合成。具体实现可调整，但每个属性必须只有一个最终写入点。每帧基于本帧基础姿态计算偏移，禁止在上一帧结果上无限累加。

动作描述至少含动作 ID、来源骨架/参考姿势、持续时间、循环、淡入淡出、身体 mask、优先级、root motion 模式、头眼接管策略、必要骨骼与可选接触信息。默认原地动作；root motion 与 Room 站位、Pet 漫游/拖拽的所有权不可冲突。

### 4.3 材质

首期语义模板为 FACE、HAIR、SKIN、CLOTH、METAL、EYE；GLASS 作为可选普通材质降级，不强行套 Toon。模板共享基础光照，特殊行为按模板开放，避免无约束的万能 Shader。

定义每个参数的单位、范围、默认值、贴图通道、UV、色彩空间、渲染状态和缺省规则；例如颜色采用何种编码、threshold 对应哪一步明暗计算、rim 受灯光影响方式。优先评估 MToon 已有语义，脸部 SDF、发丝高光等超出部分显式版本化扩展。

同一参数跨引擎可读取不代表同样画面；验收基于固定灯光、曝光、色彩管理与相机的参考场景。换模板保留蒙皮、形态键、透明裁剪、双面、深度及阴影行为。

- [ ] Room 与 Pet 可有不同环境，但模板和参数解释一致；提供标准预览判断差异是否来自舞台灯光。
- [ ] 缺贴图/旧显卡能力不足时按合同回退；性能达到 CA-00 阈值，不用大幅增加材质数掩盖实现问题。

验收：至少一个完整角色、两套参数外观；更换参数无需改节点实现；不能把模板名称存在视为对应效果完成。

## 12. CA-07：打包导入、配置和诊断

- [ ] 在目录模式通过纵向样本后增加 ZIP 导入，校验后原子安装到本机可写资产目录，失败不覆盖可用版本。
- [ ] 防止路径穿越、绝对路径、符号链接逃逸与重复路径覆盖；设文件数、单文件/解压总量和贴图资源预算。引用只允许包内资源或已授权资产，不自动访问远程 URL。
- [ ] 保持开发目录、发行可写目录、打包资源 fallback 的既有顺序；旧 GLB 可继续选择，重复包 ID/不同 revision 有明确处理。
- [ ] 提供资产选择、映射/材质/表情/动作预览与本机覆盖管理，用户文案走语义 i18n key，布局复用现有设置组件。
- [ ] 诊断包含版本、有效模板、缺骨/缺键/缺贴图、动作能力、降级原因及校准是否过期；导出脱敏报告，不能包含本机路径、私有资产内容或凭据。
- [ ] 排障只读能力优先复用后端管理面；若需要新增桌面状态上报，先定义最小脱敏摘要、scope、生命周期与总账，不上传模型。仅本机编辑所需预览/错误提示保留桌面，不建重复后台台账。
- [ ] 若持久新增审计/运行状态，同单落实只读观测；可重建缓存不为清单硬加服务端端点。

验收：有效包、损坏包、不兼容版本、越界资源、缺选配资源、更新后过期映射均有稳定结果；发行安装后加载有效，重启保持本机修正。

## 13. CA-08：验证与交付矩阵

自动验证优先复用 vitest/Rust 现有测试，新增只覆盖真实风险：schema/迁移、引用解析、重定向坐标、骨骼合成、mask、生命周期、包路径与资源限制。相关 TypeScript 检查与 Vite build；Rust 改动才运行对应检查。按开发环境文档处理沙箱 EPERM，不用 tsc 替代构建。

| 验收场景 | 自动化证据 | 真实运行证据 |
| --- | --- | --- |
| 旧 GLB、无动画、缺骨/缺键 | 兼容与降级测试 | Room/Pet 正常显示、动作不异常 |
| 两套骨架与比例 | 参考姿势/转换数值测试 | 自然站姿、动作、脚手接触 |
| 表情与眼神组合 | 权重/限角/所有权测试 | 微笑、眨眼、口型、注视同时成立 |
| 材质 | 参数与引用校验 | 标准灯光截图、运动下蒙皮/透明正确 |
| 生命周期 | 加载代次、释放、重置测试 | 连续热切换、隐藏恢复、关闭重开 |
| 包与本机覆盖 | 导入失败/迁移/缓存测试 | 发行版路径、重启、资源 fallback |
| 性能 | 预算检查与计时 | 约定设备双窗口持续运行，达 CA-00 阈值 |

- [ ] 更新 `docs/runtime-acceptance-matrix.json`，记录提交、系统、产物、时间和可复现证据；未跑项保持 not-run。
- [ ] 真实模型至少连续运行 10 分钟，观察姿态漂移、内存趋势和物理稳定；切换及前后台恢复执行完整一轮。
- [ ] 核对现有场景相机、角色找回、摆放、Pet 拖拽/漫游、聊天呈现和视频采集未回退。
- [ ] 实际缺陷记 `docs/known-issues.md`；跨仓接口变化同步后端总账。仅缺少未来增强不得冒充已发现故障。
- [ ] 无后端/手机实际消费变化时写明不适用；如新增诊断上报，只验证该条实际链路，不扩展到无关端。

验收：源码测试与真实窗口/发行包分别有结论；任何一项无法实测均保留 partial，不以截图一张代替动作与生命周期验收。

## 14. CA-09：更新建模操作文档（必交付，不可遗漏）

### 14.1 必须更新的内容

- [ ] 区分 Blender Z-up 编辑环境和导出 Y-up 坐标；具体说明何时应用变换、如何检查导出朝向，不给所有已绑定模型无条件 Apply All Transforms。

- [ ] FACE/HAIR/SKIN/CLOTH/METAL/EYE 分槽与模板选取、所需贴图及 UV/色彩空间、缺 SDF/高光遮罩如何降级；说明无法原样导出的 Blender 节点。
- [ ] 动作导入/转换、源目标参考姿势对齐、root motion、烘焙必要约束、导出 clip、全身/局部 mask、永久修正与临时表演的差异。
